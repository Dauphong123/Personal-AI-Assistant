# Web chat frontend (`frontend/`)

TypeScript browser app for the agent API `python -m backend` (API: `backend/CLAUDE.md`), a separate part of the project: it has its own server and reaches the agent only over HTTP. No framework, no runtime dependencies; dev dependencies `typescript` and `@types/node`, pinned exactly (a test checks).

```powershell
npm --prefix frontend install          # once
npm --prefix frontend run build        # src/*.ts -> dist/*.js, public/* -> dist/
npm --prefix frontend start            # serve dist/ on 127.0.0.1:5173 (-- --api ORIGIN --port N --host 127.0.0.1|localhost)
npm --prefix frontend test             # node --test on test/*.test.ts (Node runs .ts directly)
npm --prefix frontend run check        # tsc type-check of src and test
```

- `src/types.ts`: backend shapes (`ServerInfo`, `SessionInfo`, `ChatEvent`) and `PROTOCOL` (must equal `backend/server.py`). `src/api.ts`: `Api` client (`handshake`, sessions, `transcribe`, `speak`); never throws, returns `Result`. `src/state.ts`: pure reducer `apply(conversation, event)` (ignores already-seen ids, so a replay is harmless; `approvalRequest` keeps the pending approval's id, which Allow/Deny and a hands-free answer send; a spoken answer counts only if the same request still waits; `notice` events become notice items; `tool` events become `ToolItem` cards, one per `call` in the current turn, updated in place, running ones turn `stopped` when the turn is cancelled or fails; `turnStartedAt` from the opening event's `at`, and on `done` the final answer gets `seconds`), `blocks()` (``` fences → code), sidebar helpers, `statusOf` (header status text + tone: busy/approval/error/voice; names the running tool via `activeTool` + `describeTool`, e.g. "Reading main.py…"; with `now`, `elapsed` comes apart from the text so the live region is not re-announced every second) and `isThinking` (turn running, no answer text and no running tool card → the Thinking placeholder). `describeTool(name, args)` → `{doing, done, target}` for every tool in `tools.py` `TOOLS` (`search_document` = RAG; unknown → "Using x"), target one line ≤ 80 chars. `retryPrompt` (Retry / Try again: the prompt of the turn that just ended with an answer or note; null while busy/waiting/approval, after a job-notice turn, or when the turn ended on a tool card). `elapsedLabel` ("9 s", "1 min 5 s", "12 min"). `relativeTime` (sidebar: "5 min ago", "yesterday", "2 Oct"). `describeCalls` (approval card: per call a title like "Run a command"/"Edit a file", the file it touches, fields; `delete_file` is `danger`; unknown tools and extra args listed as they are), drawn by `render.renderCalls` (edit shows Replace/With in red/green). `src/markdown.ts` (pure, tested): `parseMarkdown` → block tree (headings, paragraphs, fenced code with `open` while streaming, nested lists, quotes, rules, tables) and `parseInline` (code, strong/em/del, links; unclosed markers stay literal); `safeHref` allows only http(s)/mailto, other link targets become plain text; depth-capped. `src/render.ts`: that tree → DOM (text nodes only; links open in a new tab with `noopener noreferrer`); assistant messages use it, user messages stay plain (only ``` fences). `src/render.ts` also draws tool cards (`renderTool`: `<details class="activity">`, output in a `<pre>`, no toggle while empty) and message buttons (`actionButton`, styled like Copy). `src/keys.ts` (pure, tested): `shortcut()` — Escape closes the menu, then the drawer, else stops a running turn (left to an open dialog or the rename box); `/` focuses the message box; Ctrl+K / Cmd+K (not with Shift or Alt) → `palette`, also while typing. `src/commands.ts` (pure, tested): `score`/`rank` (prefix > word start > substring > letters in order; keywords at 0.9; ties keep order) for the palette, `SLASH_COMMANDS`, `parseSlash` (only those exact names; a no-argument command followed by words, or any other `/word` such as a project path, is an ordinary message), `slashSuggestions`. `src/theme.ts` (pure, tested): `parseTheme` / `nextTheme` (system → light → dark) / `themeLabel`; `main.ts` keeps the choice in `localStorage` (`coding-assistant-theme`) and sets `data-theme` + `color-scheme` on `<html>` (none = follow the system). `src/url.ts`: token from `?token=` and the agent API address from `?api=` (`apiFrom`; `apiOrigin` accepts only a plain http(s) origin, anything else is ignored; both kept in `sessionStorage` and removed from the address bar; no `api` = the page's own origin, as with `--serve-frontend`), session id from `#<id>`; `Api(token, fetch, base)` prefixes every call and the event stream with that address. `src/handsfree.ts` (pure, tested): `PressTracker` (hold/tap/double tap), `Endpointer` (speech start/end from levels; threshold follows the noise floor), `handsFreeAction`, `insertDictation`, and the composer's voice meter: `formatDuration`, `recordingLabel` (cap shown in the last quarter), `levelToUnit` (-60..-15 dB → 0..1), `meterBars`, `handsFreeLabel` (Listening / Hearing you / Paused while the answer plays / Transcribing, plus queued prompts). `src/voice.ts`: `Recorder` (MediaRecorder, webm/opus, 60 s cap, `onLevel` via a Web Audio `LevelMeter` when available), `Player` (`onChange` pauses hands-free while it plays), `HandsFreeListener` (one mic, an Endpointer on AnalyserNode levels, `onLevel(level, speaking)` each tick, one MediaRecorder file per utterance; not unit-tested: smoke-tested in headless Chrome with `--use-file-for-fake-audio-capture`), pure `replyToSpeak` (only `done` events after the history present when the session was opened). `src/main.ts`: DOM only; handshake first (no page without it), sidebar polls `/api/sessions` every 2 s, one `EventSource` for the active session; Talk / Hands-free buttons and "Read answers aloud" only when the handshake offers voice (choice kept in `localStorage`). Talk: hold (or hold Right Ctrl) = dictation via `api.dictate` inserted into the message box at the cursor, not sent; a short click records until the next click. Hands-free (button or double tap Right Ctrl): each utterance → `handsFreeAction` → queued prompt (sent when the session is idle; a 409 re-queues), approval answer, stop, or off; stopping hands-free keeps queued prompts, "stop" or switching sessions drops them; off after 2 min without speech.
- Model (F036): with handshake `features.models`, `#model` / `#effort` selects in the header (effort only for `claude-code:*`, disabled while busy; `api.listModels` / `api.setModel`); `/model [name] [effort]`; palette "Model: <id>" entries; a `model` event is a `model` item (muted line with the privacy text), which neither starts nor ends a turn.
- Interaction (`main.ts`): Rename / Clear / Delete live in the ⋯ menu (`#session-menu`, arrow keys move, Escape closes); rename is inline (`#title-input`, also double-click the title; Enter saves, Escape cancels, blur saves); Clear and Delete ask in a `<dialog id="confirm">` (Cancel focused; no `prompt()`/`confirm()`, a test checks); code blocks (`figure.code`) and answers have Copy buttons (answers copy their markdown); `#jump` shows while the newest messages are scrolled out of view. User messages have Edit (text back into the box); the last answer has Retry and a stop/error note has Try again (CSS shows `.retry` only in `.log.can-retry > :last-child`; `send(text)` resends without touching the box's draft). Header: `#elapsed` (aria-hidden) and the Thinking line tick every second while a timed turn runs (`tickWhileBusy`); answers show `.msg-time`. Command palette `<dialog id="palette">` (combobox + listbox, `paletteItems()`: actions that fit the state, direct theme choices, other sessions; `runCommand` reuses the menu buttons, so Clear/Delete still confirm). Slash suggestions `#slash` above the message box (arrows, Tab completes, Enter runs a no-argument command; `send()` runs a parsed slash command before the busy check, so `/stop` works mid-turn).
- Look (`style.css`): colour tokens on `:root`, dark set under `prefers-color-scheme` (unless `data-theme="light"`) and again under `[data-theme="dark"]` (a test checks both define every colour); one accent (petrol); the answer being written gets class `writing` (animated left "spine"); icons are inline SVG with `aria-hidden`, icon-only buttons need `aria-label` (tested); button text lives in a `.label` span (`setLabel`). Class `.tool` is taken by the composer buttons: tool cards use `.activity*`. No web fonts (no external resources allowed).
- `public/`: `index.html`, `style.css`, copied to `dist/` by `scripts/copy-public.mjs`. `dist/` and `node_modules/` are gitignored.
- `scripts/serve.ts` (`npm start`, Node built-ins only, run as TypeScript like the tests; type-checked with `src`/`test`; tested in `test/serve.test.ts`): serves `dist/` on loopback only (default 127.0.0.1:5173, the backend's default `--frontend-origin`), Host must be `127.0.0.1|localhost:<port>`, GET/HEAD only, the backend's path rules (known types, no hidden names / `..` / backslashes / bad escapes, real path inside `dist/`), `nosniff`, `no-store`, `no-referrer`, and a CSP whose `connect-src` is `'self'` plus `--api` (default `http://127.0.0.1:8000`; a page told `?api=` something else cannot connect). `DEFAULT_PORT`/`DEFAULT_API` must equal `backend/__main__.py` `FRONTEND_SERVER_PORT`/`FRONTEND_SERVER_API` (a Python test checks).
- Rules: relative imports name the `.ts` file (`rewriteRelativeImportExtensions` turns them into `.js`); only erasable TypeScript (`erasableSyntaxOnly`: no enums/namespaces/parameter properties). Never `innerHTML`/`eval` (a test scans `src/`): model and web-page text is untrusted, inserted with `textContent` only. CSP forbids inline script/style: no `<script>` blocks, `style=` attributes or `on*=` handlers in HTML.

`tests/test_webui_frontend.py` runs `npm test`, `npm run check` and a build+serve check from the Python suite (skipped without `npm` or `node_modules`).
